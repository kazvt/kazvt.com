Continuous mode keeps the video actually playing all the time and steers it with playbackRate. Pendulum mode in normal browser video cannot do true reverse playback reliably, so this page automatically switches to a precision seek mode for pendulum. That is visually accurate, but it may repeat or skip frames.

Config

The beat frames are frame numbers inside video.mp4. Example: 0, 30, 60, 90 means 4 marked sync frames in a 30fps video.

What this does

  • Loop mode: the video keeps playing continuously and is speed-controlled so marked frames land near the MIDI beat times.
  • Pendulum mode: auto-switches to precision mode because reverse MP4 playback is not dependable in browser video.
  • The page tries data.midi first, then data.mid.
  • MIDI note-on events become the beat times.
