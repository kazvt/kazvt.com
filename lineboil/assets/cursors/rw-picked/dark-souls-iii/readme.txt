=== Dark Souls III Cursor Set ===

By: PandoraBonf

Download: http://www.rw-designer.com/cursor-set/dark-souls-iii

Author's description:

By request, here’s a cursor set from Dark Souls 3!
The textures were extracted directly from the game and slightly modified to blend nicely with the main cursor and added some extra. This set looks especially good with dark themes.

P.S. Huge thanks to THTH for allowing me to use the pointer cursor from his set — you can check out his original work here: https://www.rw-designer.com/cursor-set/mix-pointer-hands-from-videogame

Enjoy!
