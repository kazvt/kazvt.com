=== Nature Theme Pack Cursor Set ===

By: nrox653 (http://www.rw-designer.com/user/3198) pokehack@gmail.com

Download: http://www.rw-designer.com/cursor-set/natthemepack

Author's description:

ATTENTION: When using this set on Windows Vista, please disable the "Enable pointer shadow" checkbox. This cursor includes a "burnt-in" shadow for compatibility with XP (and possibly 2000, other versions might show a black mess)

This is my second set uploaded here. It's similar to the Ice Pack Pro cursors, except there's more animation and slightly more colorful. It's NOT a recolor at all though, it was made from scratch. The 3D renderer was not used at all, those 3D effects were drawn by hand. Plus it's more or less green, as if it wasn't obvious enough. Anyways, I designed it to be more for casual purposes and fun than a professional look.

You can tell which cursor goes where just by looking at the names and using common sense, so no list here ;)
