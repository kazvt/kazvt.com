# Point-and-click cursor artwork

These three animated transparent GIFs are local copies of art published in the [USAGIF transparent arrows, cursors, and pointers collection](https://usagif.com/arrows-cursors-pointers-gifs-on-transparent-background/). That page describes the collection as free to use in creative work. The original source is retained here for attribution and so the page does not depend on a third-party image host at runtime.

- `pointer-default.gif` - “Large blue cursor” artwork from the collection.
- `pointer-hover.gif` - “Cursor for a definitive click” artwork from the collection.
- `direction-right.gif` - “White arrow pointing right”; mirrored for left and rotated down for return navigation.

The GIFs are displayed as a page-local overlay instead of native CSS cursor images because animated cursor-image support varies by browser. The overlay is non-interactive and only replaces the cursor over the 3D preview.
