Reward index decorations

These GIFs are local copies from GifCities, the Internet Archive's search
collection of animated graphics from archived GeoCities pages. The reward
index does not request them from a remote host at runtime.

Each filename is the corresponding GifCities checksum. The assets were found
with the search terms "trophy", "medal", and "star" and checked frame by
frame; every frame contains transparent pixels.
