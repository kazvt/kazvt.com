# Reward edge decal GIFs

The eight-image selection and its side restrictions are configured in
[`reward/decal-pool.mjs`](../../decal-pool.mjs). The displayed set and positions are
deterministic from the reward artwork's SHA-256 asset ID; tier and username do not
affect them. The pool does not reuse an image within one reward.

The checksum-named GIFs are local copies from `blob.gifcities.org/gifcities/`.
The locally supplied GIFs are copied into this folder, including `awaw.gif` and
`WNYOPWW72P424UFMBK7YTD76GSFCYYIL.gif`.
`AJ3PGGLROVFZ4RADSQHDTT6ILHCMIGVD_repaired.gif` is left-edge only. The original
download's final frame was truncated, so the pool uses a repaired copy with its
37 complete transparent frames; the original download is kept unchanged.
`FZOIT4NKHYKHZELQATMJIGYUJM3VUZ45.gif` is right-edge only.
`S4PFGWRLGB34WVSA3KRJ6US45232D3EU.gif` is left-edge only, and
`WLDLDJVKFZKRH5VLQSGZM4EPB7TN6MEC.gif` is right-edge only.
`CWKDK64M4KFOKNEK5244P52V57DJGDPL.gif` is left-edge only, and
`FAY72EKBPY2XQ7TG6DXLZASSTYAT3HR6.gif` is right-edge only. The GIFs
`DFKBEM3QMD4SYQEUYGRXVNNZLPUJX5AO.gif`,
`AMLVTNU2URJXNELKRPSKE7NTY5VTTA4E.gif`,
`ROSN2WTVW2U2AUQKM5JYHT2JAHTA7S22.gif`, and
`PIUMSHKA5VQRPNYL5YA523BW7BVVF7IE.gif` can appear on either edge.
