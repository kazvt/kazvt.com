Comic Neue webfont files

The regular and bold WOFF2 files in this folder are from the
@fontsource/comic-neue 5.3.0 package (upstream Comic Neue font version 2.003).
They are self-hosted so the KT site does not depend on an installed system font
or a third-party font server. They are licensed under the SIL Open Font License
1.1; see OFL-Comics-Neue.txt.

Upstream project: https://github.com/crozynski/comicneue
Package: https://www.npmjs.com/package/@fontsource/comic-neue
