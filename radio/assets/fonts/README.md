# Radio emoji font

`Mona12ColorEmoji.woff2` is an unmodified webfont from Mona Font, release `2026.10.09`.
It is used for emoji glyphs in Radio track titles; the site font remains in use for
the title text itself. The font is distributed under the SIL Open Font License 1.1;
the complete upstream license is in `OFL.txt`.

- Project and source: https://github.com/MonadABXY/mona-font/tree/2026.10.09
- Upstream file: `web/Mona12ColorEmoji.woff2`
- Upstream license: `OFL.txt`
- SHA-256: `4B359B78111B5AAF088C90FA0E249FE7E44EEA5D4C2A65F94422B0207B012F02`

The Mona Font project credits Google Noto Emoji for its color palette and flag
emoji designs; see the upstream README for its full credits.
